# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within MarkItDown Studio IDE, please DO NOT report it through a public GitHub issue.

Instead, please send a report directly to the repository maintainer via GitHub Security Advisories or by emailing `gugaucb@gmail.com`.

Please include:
- A description of the vulnerability and its potential impact.
- Clear steps or a proof-of-concept (PoC) script to reproduce the issue.
- Any suggested mitigations.

We will acknowledge receipt within 48 hours and work on a fix in a private branch before publishing a security release.
